# Infinite — Desktop Releases

Public download host for the **Infinite** desktop app (macOS).

This repository holds only the published, code-signed + notarized build artifacts
(`.dmg`, `.zip`, `latest-mac.yml`) used by the desktop app's silent auto-updater
(electron-updater / Squirrel.Mac). It contains **no source code**.

## Install

Download the latest `.dmg` from the [Releases](../../releases/latest) page and open it.
After the first install, the app updates itself silently in the background — every
later version is delivered automatically on the next launch.

Builds are produced by the `Desktop Release` CI workflow and uploaded here automatically.
